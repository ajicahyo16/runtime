# Phase 3: Durable Object & SQLite Database Generator & SDK Compiler

This phase outlines the architecture of mapping Business Aggregates (e.g., *Outlet*, *Warehouse*, *BookingCalendar*) to individual Durable Objects containing internal SQLite databases, and how Lacify compiles these designs into clean REST APIs and native SDKs.

## 1. Concept: Business Aggregates & Boundaries
Instead of modeling database tables or low-level entities (like *Orders*) as separate databases, Lacify maps high-level **Business Aggregates** directly to **Durable Objects containing SQLite databases**:
- **Consistency Boundary**: A single DO/SQLite instance represents the transactional boundary (e.g., all orders, stock movements, and cashier shifts for *Outlet Jakarta* live inside its private SQLite brain).
- **No Manual DO Management**: Developers design schemas visually or via AI prompts; they never write `env.OUTLET_DO.idFromName(outletId)` or SQLite initialization migration files manually.

---

## 2. Business Object Designer & Modeling
Developers build models inside the modeling environment using three components:
1. **Business Objects & Properties**:
   - Defines properties (e.g., `Order` has `subtotal`, `tax`, `total`, `createdAt`).
2. **Allowed Actions (Commands)**:
   - Specific functions permitted on the aggregate (e.g., `CreateOrder`, `AddItem`, `ApplyDiscount`, `Pay`).
3. **State Machine Transitions**:
   - Delineates progress of an object through states (e.g., `Draft` → `Open` → `Paid` → `Refunded`).

---

## 3. The Runtime Compiler Pipeline
When the developer clicks **"Compile"**, the webapp sends the Project Spec to the Lacify Compiler, which outputs:
- **SQLite Database Migrations**: Auto-generated DDL and transition SQL commands.
- **Durable Object Code**: Javascript/Wrangler workers containing the SQLite schema and transition handlers.
- **API routes & OpenAPI Manifest**: Visual documentation and endpoints (e.g., `POST /v1/outlets/{outletId}/orders/{orderId}/pay`).
- **TypeScript & Kotlin SDK**: Fully typed clients that developers use directly.

### SDK Client Integration Example:
Frontend developers import the generated SDK to perform actions safely without raw SQL or HTTP boilerplate:
```typescript
// Strongly-typed SDK generated by Lacify Compiler
await lacify.inventory.transferStock({
  sourceWarehouseId: "wh-jakarta",
  destinationWarehouseId: "wh-surabaya",
  productId: "prod-992",
  quantity: 150
});
```

---

## 4. Visual Dashboard & Validation Controls
- **Aggregate Designer Panel**: Lists active aggregates, business objects, state timelines, and client SDK previews.
- **AI App Builder**: Parses natural language prompts to generate model proposals (Aggregates, Objects, Actions, States) for review before compilation.
- **Database size guard**: Circular alerts warnings when DO SQLite size exceeds 8 GB (out of 10 GB limit) to prevent write locks.
